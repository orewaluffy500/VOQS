# VOQS Engine

VOQS is a simple 2D game which is mainly designed to be heavily modified via Plug-Ins.

Plug-Ins are coded in lua and can add various things to the game such as:
- New blocks
- New logical blocks
- New mechanics
- Overhauls

  And more.

I've been working on VOQS since i've always wanted to mod games but for some reason every time i tried, Even the example code would fail.

So, "Fine, I'll do it myself" and decided to make my own modding engine.
